# Splash Screen & Icon

The splash screen provides a polished first-impression while the app initializes. It features:

- Animated logo with rotation effect
- Pulsing background gradient
- Loading dots animation
- Fade-out transition to main UI

The icon is a blue (#5382F6) square that matches the TridentDroid brand.

## Files

- `src/components/SplashScreen.tsx` — Splash screen component
- `src/App.tsx` — Updated to show splash on startup
- `src-tauri/icons/icon.ico` — Multi-size Windows icon
- `app-icon.png` — 1024x1024 app icon for Tauri
